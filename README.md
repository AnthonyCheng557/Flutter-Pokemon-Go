# Terpiez Go

The first is Flutter Pokemon Go.
Flutter Pokémon Go is a mobile app inspired by the original Pokémon Go game, built using Flutter and Dart. It replicates core gameplay mechanics while using modern app architecture and open source APIs. The app features a full user authentication system. It also uses Redis as its primary database, storing user data such as captured Pokémon, player stats, and location history. To enhance performance and reduce API calls, the app implements local caching with packages like shared_preferences, allowing for offline gameplay and quick access to recent data. A key feature is real-time geolocation tracking, powered by the geolocator and google_maps_flutter packages. This enables the app to track the user's movement in the real world and interact with nearby "Pokemons".
